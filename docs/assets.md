# Asset provenance and licenses

Everything visual in Snailpost is either original work made for this project or openly licensed. The moodboard (`Untitled design.pdf`) was used only as a reference for mood: paper, stamps, single-stroke spirals, warm clay on cream, moss as a calm accent. No logo, lettering or artwork from it was traced or reused.

## Original assets (made for Snailpost)

| Asset | File(s) | How it was made |
|---|---|---|
| Snail mark and favicon | `public/brand/snail-mark.svg`, `favicon.svg` | Hand-specified SVG paths in `src/lib/brand.ts`: a snail whose shell is an envelope, sealed with a spiral wax seal. Generated by `scripts/gen-brand.mts`. |
| Four stamps | `public/brand/stamp-*.svg` | Breakfast Club, On My Way, Little Victories and Home Again. The perforated edge is generated by `perforatedRect()`, and the artwork is simple original paths. |
| Envelope, sprig, sun, steam curl, postmark, cancellation lines, tape, paper grain | `public/brand/*.svg`, `src/components/brand.tsx` | Original SVG. The spiral uses a seeded wobble so its imperfection is the same on every render. |
| Sample illustrations | `public/sample/{breakfast,walk,practice,dinner}.{svg,jpg}` | Original gouache-style SVG scenes generated by `scripts/gen-sample.mts`, rasterized to JPEG with Playwright so they behave exactly like real photos. They are labeled as illustrations in the app. |
| Sample narration | `public/sample/narration.m4a` | Computer-generated speech (macOS `say`, voice "Samantha"), converted with `afconvert`. It is labeled in the app as computer-generated, not a real recording. |

## Test fixtures

`tests/fixtures/corrupt.jpg` is random bytes and `notes.txt` is plain text; both exist only to test upload errors. The voice-recording e2e test uses Chromium's built-in fake microphone (a synthetic tone), which is a fixture, not a voice.
